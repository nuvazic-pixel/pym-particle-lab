# PYM Particle Lab

**v0.1.1 — M0 / M1 / M2 falsification sandbox**

PYM Particle Lab compares a standard conservative system, an explicit phenomenological memory hypothesis, and a conventional hidden-environment comparator.

> **Scientific status:** PYM is a computational hypothesis. It is not a discovered particle or an established physical theory.

## Frozen model matrix

- **M0 — Standard:** conservative reference dynamics.
- **M1 — PYM:** explicit history-dependent memory kernel coupled phenomenologically to the observable state.
- **M2 — Hidden environment:** conservative particle + auxiliary harmonic degree of freedom, used as the first conventional-memory comparator.

The PYM decoupling limit is `lambda_pym -> 0`.

For v0.1.x the memory update is an exponential kernel:

`M[k+1] = exp(-dt/tau_M) M[k] + (1-exp(-dt/tau_M)) J[k]`

`J` is an **interaction signal**, not assumed to be physical information.

## Provenance

- `MODEL_INPUT`: mass, charge, initial position/momentum
- `HYPOTHESIS`: lambda_pym, tau_M, J, M
- `DERIVED`: energy, momentum, divergence metrics
- `NUMERICAL`: dt, integrator/truncation/floating-point effects
- `EMPIRICAL`: reserved for real measurements; none in v0.1

## Correctness gates

1. **Baseline invariance:** different PYM memories cannot change M0.
2. **Energy accounting:** conservative M0/M2 are tested using the energy of the complete modeled system.
3. **Momentum:** only enforced where translational symmetry/no external force actually implies momentum conservation.
4. **Time-step convergence:** claimed effects must stabilize as dt decreases.
5. **Deterministic replay:** identical inputs must reproduce identical outputs/event journals.

A fixed numerical tolerance is not a law of physics. If an integrator cannot meet a gate at a chosen dt, dt/integrator convergence must be demonstrated rather than relabeling numerical drift as physics.

## Experiment 001 — Double History

Two runs begin with the same observable particle state and different histories. M0 must be invariant to that hidden history. M1 measures the explicit PYM-history divergence. M2 asks how much of a history-dependent trajectory can already be generated by ordinary hidden degrees of freedom.

The first M2 implementation is intentionally minimal: one conservative auxiliary oscillator integrated with velocity Verlet. A damped bath requires explicit energy accounting for the reservoir/dissipated channel and is therefore not used for the conservative energy gate.

## Critical interpretation boundary

Failure of a **single oscillator** to fit a PYM trajectory is **not** evidence that no conventional bath can reproduce it. Mori–Zwanzig / Caldeira–Leggett-style environments can contain many modes and generate broad classes of memory kernels.

Therefore the eventual falsification problem is stronger:

> Does a PYM observable exist that cannot be represented, within stated assumptions and uncertainty, by the admissible class of conventional hidden-environment models?

A nonzero `D_PYM - D_bath` for one selected bath parameter set is only a model-comparison residual. It is not a unique PYM signature.
